# Жабий планер для Android

Календарь-планер с жабками: заметки по часам, смены, цикл, дела без даты, стикеры и напоминания.
Уведомления приходят, даже когда приложение закрыто, и восстанавливаются после перезагрузки телефона.

## Как получить APK (без установки программ, через GitHub)

1. Зарегистрируйся на https://github.com (бесплатно).
2. Нажми **New repository**, назови его `zhabiy-planer` и нажми **Create repository**.
3. На странице репозитория нажми ссылку **uploading an existing file**.
4. Распакуй архив и перетащи в окно браузера **всё содержимое** папки `zhabiy-planer`: папки `android`, `www`, `.github` и файлы рядом с ними. Нажми **Commit changes**.
5. Открой вкладку **Actions**. Там сама запустится сборка «Собрать APK» и через 5–7 минут станет зелёной.
6. Нажми на эту сборку, внизу в разделе **Artifacts** скачай `zhabiy-planer-apk`. Внутри будет `zhabiy-planer.apk`.
7. Перекинь APK на телефон, открой его и разреши установку из этого источника.

Если папка `.github` не загрузилась (на Mac она скрыта), создай файл вручную:
**Add file → Create new file**, имя `.github/workflows/build-apk.yml`, и вставь в него содержимое файла
`.github/workflows/build-apk.yml` из архива.

## Первый запуск на телефоне

- Разреши уведомления, когда приложение спросит.
- На вкладке «Календарь» в карточке «Уведомления» нажми **Точное время** и включи
  «Будильники и напоминания», чтобы напоминания приходили минута в минуту.
- На некоторых телефонах (Xiaomi, Huawei, Honor, Samsung) стоит ещё отключить экономию батареи
  для приложения: Настройки → Приложения → Жабий планер → Батарея → «Без ограничений».

## Если хочется собрать на своём компьютере

Нужны Node.js 22 и Android Studio.

```
npm ci
npx cap sync android
npx cap open android
```

В Android Studio: Build → Build App Bundle(s) / APK(s) → Build APK(s).

## Что где лежит

- `www/index.html` — сам планер (весь интерфейс и логика).
- `android/` — Android-обёртка (Capacitor), иконка и значок уведомлений.
- `.github/workflows/build-apk.yml` — автосборка APK на GitHub.
